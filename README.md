# alexw.clientsmcp

Первый клиентский MCP-сервер для 1С-Битрикс. Превращает любой сайт на Битрикс в MCP-сервер для языковых моделей, поддерживающих [Model Context Protocol](https://modelcontextprotocol.io) — Claude, GPT и других.

LLM получают доступ к данным сайта (профиль клиента, инфоблоки, поиск, фильтрация) через стандартный MCP-протокол без отдельной инфраструктуры — всё работает прямо на вашем Битрикс-хостинге.

## Возможности

- **MCP Streamable HTTP transport** — стандартный JSON-RPC поверх HTTP, работает с любым MCP-клиентом
- **Bearer-авторизация по токенам** — каждый токен привязан к пользователю Битрикс, ограничение по списку доступных инструментов
- **Универсальный инструмент для инфоблоков** — поиск, фильтрация по свойствам, постраничная навигация, динамические LLM-фильтры; поддержка множественных и кастомных свойств
- **Шаблоны инструментов** — пять готовых пресетов (поиск по ИБ, карточка по ID, фильтруемый список, список по разделу)
- **Админка** — список и редактирование инструментов и токенов прямо в админ-панели Битрикс
- **Встроенный инструмент `get_profile`** — данные текущего пользователя

## Установка

1. Скопировать модуль в `local/modules/alexw.clientsmcp/`
2. В админке Битрикс: «Marketplace» → «Установленные решения» → установить `alexw.clientsmcp`
3. Создать токен: «Сервисы» → «MCP-сервер» → «MCP-токены» → «Создать токен»
4. Настроить инструменты: «Сервисы» → «MCP-сервер» → «MCP-инструменты» → «Создать из шаблона»

## Подключение к Claude Code

```bash
claude mcp add --transport http my-bitrix https://your-site.ru/ \
    --header "Authorization: Bearer mcp_your_token"
```

После подключения LLM сможет вызывать инструменты, которые вы настроили в админке.


## WebMCP: инструменты сайта для браузерных AI-агентов (v2)

Начиная с версии 2.0 модуль поддерживает [WebMCP](https://github.com/webmachinelearning/webmcp) —
инструменты сайта становятся доступны AI-агентам, работающим внутри браузера
(Chrome 149+, ChatGPT Desktop, Edge), через `document.modelContext`.

Один реестр инструментов — два канала:

| Канал | Клиент | Авторизация |
|---|---|---|
| MCP Streamable HTTP | Claude Code, GPT, другие LLM-платформы | Bearer-токен |
| WebMCP (браузер) | AI-агент в браузере посетителя | Сессия сайта |

**Как включить:** в карточке инструмента отметьте «Доступен браузерным агентам (WebMCP)»
(флаг `browser_safe`). На всех публичных страницах модуль подключает `webmcp.js`,
который регистрирует помеченные инструменты через `document.modelContext.registerTool`.
Браузер без поддержки WebMCP скрипт игнорирует — на работу сайта это не влияет.

**Модель безопасности браузерного канала:**

- исполняются только инструменты с флагом `browser_safe`; требующие авторизации —
  только для залогиненного посетителя;
- Bearer-токены в браузер не попадают — исполнение идёт от имени сессии посетителя;
- POST защищён `bitrix_sessid`, rate-limit 60 запросов в минуту на сессию;
- включайте флаг только для read-only инструментов (поиск, карточки, профиль).

**Endpoint:** `GET/POST /alexw-clientsmcp-webmcp.json`
(GET — каталог инструментов и sessid, POST — исполнение `{sessid, name, arguments}`).

Отключить канал можно опцией `webmcp_enabled = N` в настройках модуля.

**Обновление с 1.x:** добавьте колонку `BROWSER_SAFE CHAR(1) DEFAULT 'N'`
в таблицу `alexw_mcp_tools`, перекопируйте admin-файлы и `install/js`,
переустановите модуль (таблицы при удалении не дропаются).

## Архитектура

- `lib/Interceptor.php` — перехват MCP-запросов через `OnProlog` по заголовку `Accept: application/json, text/event-stream`
- `lib/McpServer.php` — JSON-RPC роутер: `initialize` / `tools/list` / `tools/call`
- `lib/Auth.php` — Bearer-токен → USER_ID Битрикс
- `lib/ToolsRegistry.php` — динамический реестр инструментов из БД
- `lib/Tools/IblockTool.php` — универсальный инструмент для инфоблоков (операции `list` и `get`)
- `lib/Tools/GetProfileTool.php` — встроенный инструмент профиля
